Install on Windows

It takes a couple of minutes, then setup guides you through the rest.

  1. Open the downloaded Sidedoor-windows-x64-setup.exe.
  2. Follow the installer.
  3. Open Sidedoor from the Start menu. Setup opens in your browser.

Sidedoor for Windows is signed by David Omofonma. Because it is new, Windows may still show "Windows protected your PC" for a while; if it does, click More info, check the publisher says David Omofonma, then click Run anyway.

The installer's SHA256 checksum is:

__WIN_SHA256__
